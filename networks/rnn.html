Elman network

Simple recurrent network — the hidden layer is copied into context units
Elman — Finding Structure in Time, Cognitive Science 14(2):179–211, 1990. The copy is one-for-one with fixed weight 1.0; it develops a proposal by Jordan (1986), which feeds back the output instead
speed 1.0×
computation graph
equations
ht = σ(W xt + U ht−1 + b)
yt = σ(V ht + c)
the context layer is ht−1 verbatim — no weights on the copy
Elman used the logistic σ; tanh is the usual modern choice for the hidden layer
